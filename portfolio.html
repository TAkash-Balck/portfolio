CampusVote · Student Council Election 2026

View on GitHub

A voting app for student council elections with email sign-in, role-based access, voice-assisted voting and a live results dashboard. It runs entirely in the browser with no framework or backend.

  • Role-based access control for Voters (students) and Admins (faculty), with sessions that persist across page refreshes.

  • Voice-assisted voting: say a candidate's name to vote and hear spoken confirmation, using the Web Speech API.
