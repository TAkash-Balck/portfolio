# Personal Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript (no frameworks).

## Features

- Semantic structure: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
- Sections: Hero, About, Skills, Projects, Contact
- Fully responsive (tested at 375px, 768px and 1280px+)
- JavaScript interactions: dark mode toggle (saved in `localStorage`), mobile nav toggle, project filter, smooth scrolling
- Accessible: skip link, ARIA labels, keyboard focus styles, reduced-motion support

## Tech Used

HTML5, CSS3 (custom properties, Grid, Flexbox, media queries), vanilla JavaScript

## Run Locally

```bash
git clone https://github.com/TAkash-Balck/portfolio.git
cd portfolio
```

Open `index.html` in a browser, or use the VS Code **Live Server** extension for live reload.
